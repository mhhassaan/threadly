# Threadly brand assets

- `threadly-logo-original.png`: selected ImageGen artwork, unchanged, with its original white background.
- `threadly-mark.svg`: clean project-native vector adaptation of the connected reading-line concept for small UI placements. This is a new geometric adaptation, not an exact raster trace.
- `DESIGN-NOTES.md`: original design rationale and prompt set.

The app pairs the blue SVG symbol with the Jersey 25 wordmark already requested for navigation. The wordmark inherits the current theme's text color, so it works in light and dark modes. The symbol is also used for the favicon, footer and PNG-export brand header. Default user profile pictures remain user silhouettes.
